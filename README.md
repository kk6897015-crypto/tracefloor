# TraceFloor

React + TypeScript + Vite project.

## Overview
TraceFloor is a frontend application built with the modern React/Vite toolchain.

## Tech stack
- React
- TypeScript
- Vite
- Oxlint

## Local development
```bash
npm install
npm run dev
```

## Repository structure
- `src/` — React application source
- `public/` — static public assets
- `docs/` — project documentation
- `tests/` — tests when added

## Production build
```bash
npm run build
npm run preview
```
